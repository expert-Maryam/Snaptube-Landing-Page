# Snaptube Landing Page Project

This folder contains the complete source code for the uploaded Snaptube landing page.

## Project structure

- `index.html` — main HTML markup
- `css/styles.css` — all extracted CSS styles
- `js/app.js` — all extracted JavaScript
- `assets/` — folder for local images, icons, screenshots, or other media
- `project-info.json` — basic project metadata

## How to run

1. Extract the ZIP file.
2. Open the `Snaptube_Landing_Page_Project` folder.
3. Double-click `index.html`.
4. Open it in Chrome, Edge, Firefox, or another modern browser.

No npm, React, WordPress, PHP, XAMPP, or backend is required for the current frontend version.

## Notes

- The visual layout and functionality come directly from the uploaded HTML file.
- CSS and JavaScript were separated into dedicated source files to make the project easier to edit and submit.
- If the original page uses remote images, fonts, or external URLs, an internet connection may still be needed for those assets to load.
- You can place downloaded images or icons inside the `assets/` folder later and update their paths in `index.html` or `css/styles.css`.
