## Run the project

Extract the ZIP and open `index.html` in a modern browser.

This is a frontend project, so no npm installation, PHP, XAMPP, React, WordPress,
or database is required to preview the current version.

## Editing

- Page structure/content: `index.html`
- Design, responsiveness, animations: `css/styles.css`
- Interactions and motion behavior: `js/app.js`
- Local media: `assets/images/` and `assets/icons/`

## Important

The source includes external resources such as Google Fonts and may contain
remote resources/placeholders. Internet access can therefore be required for
some resources.

Search for `{{DOWNLOAD_URL}}` and replace it with the real download destination
before production use.
